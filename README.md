## Dados

Os dados brutos (mensagens do Telegram e vídeos do YouTube) não estão incluídos neste repositório por questões éticas e de privacidade. A base de dados é produzida e custodiada pelo Laboratório de Humanidades Digitais da UFBA (LABHDUFBA).

**Resumo dos dados:**

- **Telegram:** 2.917 ocorrências em grupos e canais de extrema direita (jan/2020–mai/2026)
- **YouTube:** 1.032 vídeos em canais de extrema direita (jan/2020–mai/2026)
